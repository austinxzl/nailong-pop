# 奶龙碰碰乐 · Nailong Pop

一个独立实现的中文物理合成小游戏。代码、界面、碰撞解算、欢乐值和连击机制均为本项目编写；未使用参考游戏的源码、界面或素材。角色直接显示透明抠图，不使用圆形底盘；碰撞边界根据图片的透明轮廓生成凸多边形近似。

## 游戏

移动鼠标并点击投放；触屏拖动瞄准、松手投放。相同形态合成下一形态。方向键移动，空格投放，P 暂停。

连续 2.7 秒内的合成会增加连击倍率，最高 5 倍。合成积攒欢乐值，蓄满后可“震一震”重新排列。超过警戒线持续 3 秒后结束本局。最后一张捧腹大笑奶龙是最终形态；两只最终形态相碰可获得 800 基础分并化为礼花。

最高纪录和个人排行榜仅保存在当前设备的浏览器。个人榜保存已结束或主动重开局的前五名成绩，手机上位于游戏下方，电脑上位于左下角。没有登录、广告、付费或联网排行榜。

## 运行和发布

纯静态网站，无构建和第三方运行依赖。可在此目录运行 `python3 -m http.server 8000`，然后访问本地 8000 端口。

GitHub Pages：仓库 Settings → Pages → Deploy from a branch → main → /(root)。所有资源使用相对路径，支持项目站点。

## 素材说明

六张角色图片由用户提供，通过内置 imagegen 工具做透明背景提取。奶龙角色本身及用户提供的参考图片不是本项目创作。源代码原创不等于角色原创。公开或商用时应自行确认角色及图片的使用授权。

`assets/dragon-1.png` 至 `assets/dragon-6.png` 对应用户上传顺序；游戏进化顺序为 2、5、3、1、4、6。第六张始终是最终形态。生成提示词详见 `ASSET-PROMPTS.txt`。

代码没有从参考站点复制。基础的“相同物体碰撞合成”是本游戏的通用玩法起点，原创部分为独立物理实现、界面、六形态安排、连击计分、欢乐震场及最终形态效果。
